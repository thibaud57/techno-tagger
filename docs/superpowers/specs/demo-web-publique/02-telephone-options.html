La démo sur un téléphone

Rendus tirés de la maquette cliquable du design system, chargée depuis l'export local. Les écrans sont à l'échelle d'un téléphone de 390 × 844. La maquette garde une fenêtre de 1280 × 800 : l'app réelle remplirait la hauteur restante de l'écran.

Sans réglage

Actuel

Le téléphone met la page à sa largeur, 390px, comme index.html le lui demande. L'app n'a pas de largeur minimale dans la page (seule la fenêtre Tauri impose 1024px), donc ses colonnes et ses barres se compriment et se chevauchent. Non montré : la maquette a une taille fixe et ne se comprime pas comme l'app.

Page déclarée à 1280px dans le build de démo

Recommandé

Une ligne dans la page de démo : <meta name="viewport" content="width=1280">. Le navigateur du téléphone affiche l'app entière réduite. Le visiteur zoome avec deux doigts, puis fait glisser. Un navigateur d'ordinateur ignore cette ligne. Les deux premiers écrans sont cliquables.

Ce que la page ne montre pas : sur un vrai téléphone, le zoom à deux doigts est fluide et le texte reste net à toutes les échelles.
